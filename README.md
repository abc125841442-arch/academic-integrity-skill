# academic-integrity

An [Agent Skill](https://skills.sh) for reviewing student work for AI use and originality.

```
npx skills add <your-github-user>/academic-integrity
```

## What it does

- **Workflow** — originality, AI detection, process evidence, conversation
- **Evidence hierarchy** — from conclusive (admission) to weak (detector alone)
- **Score interpretation** — with false-positive caveats
- **Reporting and fairness** — consistent, documented, responsive

See [`SKILL.md`](./SKILL.md) for the full instructions.
